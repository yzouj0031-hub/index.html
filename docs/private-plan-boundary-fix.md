# 私密计划泄露修复记录

基线：远端 main 的 546cfc8（PR #209），2026-09-09 拉取。

## 已复现

自由输出在公开发言后附带 `[计划]内容`、但漏写 `[/计划]` 时，
旧解析器会把计划内容放进 `game`，而 `plan` 为空。
公共历史和后续玩家上下文会把这部分当作正式发言。
这是与用户战报中赤井计划泄露相同的输出形态；
没有该局原始 API 请求/响应，不能据此确认该局所有输入细节。

## 本次修改

- 在发言/行动兜底解析之前统一分离计划，兼容尖括号、中英文方括号、混合闭合及漏闭合。
- 漏闭合时只在明确的后续字段标签处恢复解析；无明确边界的尾部保留为私密计划。
- 网页粘贴、投票和技能选择使用同一分离函数，计划内的未来目标不参与当前行动识别。
- 公共历史与朗读入口再次分离计划，覆盖绕过 API 解析的导演/手动输入。
- 计划保留在行动者自己的字段；普通的“我计划……”发言以及真假身份声明不做语义删改。
- 中英文客户端均已修改；英文客户端目前没有中文版本的增量投票接力界面。

## 范围

这次解决的是带计划标记的内容泄露。它不保证模型的推理质量，
也不自动修复没有任何标记的内心独白或已被旧对局传播的历史信息。
关于狼刀阻止毒药、保护目标估计等博弈错误，需要单独核对当时的模型输入，
不能仅凭战报断言原因在提示词或架构。
